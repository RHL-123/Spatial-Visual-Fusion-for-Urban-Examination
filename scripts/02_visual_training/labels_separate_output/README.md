# YOLO 训练标签数据流可视化统计 (Labels Statistics)

本文件夹 (`labels_separate_output`) 存放了在 YOLO 训练前或训练初期基于数据集生成的标签统计可视化图片。这些图表主要用于帮助我们了解数据集的类别分布、目标位置和包围框尺寸等关键信息。

## 包含的图片内容说明

结合文件夹中生成的图片，它们分别代表以下几个方面的统计与分析：

### 1. 类别数量分布柱状图 (Class Instances Distribution)
- **内容**：展示了数据集中每个类的实例（标签）数量。
- **作用**：直观地反映数据集的**类别不平衡情况**。通过图片可以看出，`addition_balconies_windows`（加装阳台窗户）数量远远高于其他类别（高达23140个），而 `pipeline_damage`（管道破损）等类别比较稀缺。这呼应了之前使用欠采样和过采样策略的必要性。

### 2. 目标中心点分布热力图 (Bounding Box Centers - x vs y)
- **内容**：展示了所有目标包围框（Bounding Box）中心点在图像坐标系（通常为归一化的 `x` 和 `y`）中的分布相对位置。
- **作用**：用于观察目标在图像中出现的偏好位置。通常中心点密集区域颜色较深。从图中可以看出大多目标集中分布在图像中间或某些特定水平/垂直轴线上。

### 3. 目标宽长比热力图 (Bounding Box Sizes - width vs height)
- **内容**：展示了所有目标的宽度（`width`）和高度（`height`）在归一化（0~1）后的散点分布或热力图分布。
- **作用**：用于观察目标总体上是“小目标”、“中目标”还是“大目标”，以及它们的长宽比趋势。这对配置 YOLO 模型的 Anchor Bounding Box（锚框）尺度的先验非常重要。图中偏底部的深蓝色区域表面存在大量的小尺度目标。

### 4. 包围框形状叠加图 (Bounding Box Overlays)
- **内容**：不同颜色线条叠加的包围框集合。
- **作用**：将大量不同类别的包围框尺寸和长宽比例按中心点对齐叠加在同一张图上，不同颜色对应不同类别。用于让人直观感受各类目标在实际画面中的常见形状和大小占比。

## 数据集溯源

本组统计图对应的数据集为 **`datasets_balanced`**（智能欠采样数据集），具体统计范围是其下的 **`train` 训练集**。以下是通过图表数字反推验证的过程：

### 1. 稀有类（100% 绝对保留）验证
代码中规定包含类别 `0, 5, 6` 的图片 100% 保留，期望值为 `原始数量 × 80%`（训练集划分比例）：

| 类别 | 原始总数 | 理论训练集数量 (×80%) | 图表实际数量 | 判定 |
|---|---|---|---|---|
| `pipeline_damage` (0) | 774 | 619 | **606** | ✅ 吻合 |
| `illegal_renovation_expansion` (5) | 4080 | 3264 | **3280** | ✅ 吻合 |
| `elevator_addition` (6) | 4962 | 3969 | **3948** | ✅ 吻合 |

### 2. 中等类（50% 概率保留）验证
代码中对类别 `2, 3, 4` 执行 50% 保留策略，期望值约为 `原始数量 × 40%`（80% 训练集 × 50% 保留率，实际略高因为部分图片会"沾光"稀有类被 100% 保留）：

| 类别 | 原始总数 | 理论期望值 (×40%) | 图表实际数量 | 实际保留比例 | 判定 |
|---|---|---|---|---|---|
| `wall_damage` (4) | 6898 | 2759 | **2946** | ≈42% | ✅ 吻合 |
| `no_aging_place_modifications` (3) | 7593 | 3037 | **3453** | ≈45% | ✅ 吻合 |
| `public_spaces_illegal_occupation` (2) | 9536 | 3814 | **4591** | ≈48% | ✅ 吻合 |

### 3. 泛滥类（纯阳台图仅保留 10%）验证
`addition_balconies_windows` (1) 原始总数 47652，未清洗时训练集应有约 38121 个框。
- 📊 图表实际数量：**23140**，砍掉了近 1.5 万个阳台框
- 未被砍到理论最低值（约 3800），是因为大量阳台框与稀有类/中等类出现在**同一张图片**中，"沾光"被一起保留（业务场景中违建经常伴随出现）

### 结论

| 数据集 | 特征 | 是否匹配 |
|---|---|---|
| `datasets/`（原始增强数据集） | 各类别数量趋同（增强平衡后柱子应等高） | ❌ 不匹配 |
| `datasets_balanced`（智能欠采样数据集） | 稀有类完整保留、中等类约减半、泛滥类大幅削减 | ✅ **完全匹配** |

这些图片是由 `plot_labels_custom_font.py` 或 Ultralytics 系统默认方法生成的分析图，为训练前的**数据增强**、**类别均衡平衡决策**和**超参数调整**提供了直观的几何和统计学依据。
